# Release Input

Temporary local staging area for Majik Signature Desktop installers.

Example:

```text
release-input/
└── 0.17.0/
    ├── Majik-Signature-0.17.0.exe
    ├── Majik-Signature-0.17.0.msix
    ├── Majik-Signature-0.17.0.deb
    └── Majik-Signature-0.17.0.AppImage

```

Files placed here are ignored by Git and uploaded directly to GitHub Releases.
